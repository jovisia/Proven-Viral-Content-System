# Prompt templates for Magic Hour text-to-video

Prompts must be 1–2000 characters. Describe **visuals**, not editing instructions.

## Short-form hook

```
[Subject] [action] in [environment]. [Camera movement]. [Lighting/mood].
Style: [cinematic/animated/documentary]. [Duration]-second clip.
```

**Example:**
```
A laptop screen glows in a dark room as AI-generated video clips appear in rapid
sequence. Camera slowly pushes in. Neon blue lighting, cyberpunk mood.
Style: cinematic tech demo. 8-second clip.
```

## Product demo visual

```
Clean [product category] visualization: [specific scene showing the feature].
Smooth [camera type] movement. Bright, modern lighting. Professional SaaS aesthetic.
```

## Cinematic B-roll

```
Wide establishing shot of [location/scene]. [Weather/time of day].
Slow [pan/dolly/tracking] shot. [Color grade description]. No people.
```

## Meme / reaction backdrop

```
Exaggerated [emotion] reaction scene: [character/situation].
Quick zoom, saturated colors, meme-style composition. Humorous tone.
```

## Tips

- Avoid text overlays in prompt (add in post-production).
- Specify camera movement — Magic Hour handles motion well.
- Match duration to platform (see content-types reference).
- For audio-enabled generations, describe ambient sound context in prompt text.
