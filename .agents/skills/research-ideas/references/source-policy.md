# Research source policy

## Do

- Search the web for current trends (last 3–6 months).
- Name the platform or publication when citing a trend.
- Report contradictions ("TikTok favors X, but YouTube Shorts trend Y").
- Prefer primary sources: platform blogs, creator case studies, competitor public posts.

## Don't

- Invent viral metrics ("this gets 10M views") without a source.
- Scrape private or paywalled content.
- Recommend excluded topics from `content_rules.exclude`.
- Copy competitor content verbatim — adapt formats, not scripts.

## When sources are thin

Say so explicitly: "Limited public trend data for [niche] — these ideas are based on adjacent categories and your profile."

## Saving preferences

Only persist preferences the user explicitly confirms. Show the exact text before writing to `profile.json`.
